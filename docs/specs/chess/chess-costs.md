# Chess — Cost Considerations

## Related Spec
`./chess.md`

## Resources Required
- **Hosting:** GitHub Pages.
- **CI:** GitHub Actions, to build and deploy.
- **Licenses:** no paid ones. Fairy-Stockfish and ffish.js are GPL-3.0, and the site ships them, so the site's source must be GPL-compatible. That's fine for a public repo. The piece set must have a license that allows redistribution, with attribution.

## Budget Status
No budget needed. It's a personal project.

## 3-Year Cost Projections
Expected cost is $0. All computation happens in the player's browser, and the site is small static files, far below the GitHub Pages limits (1 GB per site, 100 GB/month of bandwidth).
